# ADR 0003 — PostgreSQL владеет содержимым, Qdrant является производным индексом

**Статус:** принято.

## Решение

Документ, ревизия, нормализованный текст, чанки и происхождение сохраняются в
PostgreSQL. Qdrant получает векторы только готовых ревизий и может быть полностью
восстановлен из PostgreSQL.

## Последствия

Индексация имеет явные состояния `pending/ready/failed`; поиск сначала отбирает
актуальные готовые ревизии. Частичный сбой не делает векторный индекс источником
истины, но требует сверки и идемпотентного восстановления.
