# ADR 0013 — Офлайн-проверка использования инструментов по неизменяемым трассам

**Статус:** принято.

## Решение

Оценивать заранее размеченные сценарии агента по сохранённым неизменяемым трассам:
выбору инструмента, аргументам, завершению, лишним вызовам и recovery.

## Последствия

Можно воспроизводить проверку без новых платных вызовов. Статус выполнения не равен
семантической правильности; происхождение rubric и границы набора обязательны.
