# ADR 0012 — Типизированный MCP-калькулятор поверх stdio

**Статус:** принято.

## Решение

Предоставить один калькулятор по MCP/stdin-stdout с явной JSON-схемой и ограниченным
вычислением `Decimal`; клиент агента вызывает его через адаптер.

## Последствия

Проверяются discovery и invocation без сетевого сервиса. MCP отделяет tools,
resources и prompts; наличие локального инструмента не даёт агенту произвольный
доступ к системе.
