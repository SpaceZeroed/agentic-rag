# ADR 0010 — Асинхронная HTTP-граница над существующими RAG-сервисами

**Статус:** принято.

## Решение

FastAPI предоставляет загрузку, запрос, health и SSE; lifespan создаёт зависимости,
схемы валидируют входы, а блокирующие операции выполняются вне event loop. Проверка
финальных ссылок общая для обычного и streaming-ответа.

## Последствия

HTTP остаётся адаптером, а не местом доменной логики. Нужны лимиты конкуренции,
тайм-ауты и корректная отмена; `async def` сам по себе не ускоряет CPU-вычисления.
