# ADR 0002 — Валидируемый запуск и воспроизводимые инструменты Python

**Статус:** принято.

## Решение

Использовать Python 3.12+, `uv` и lockfile, Hatchling, Pydantic Settings с префиксом
`RAG_`, стандартное логирование в JSON, pytest, Ruff и строгий mypy. Версионируются
`pyproject.toml` и `uv.lock`, но не `.venv` и секреты.

## Последствия

Настройки валидируются при старте, а проверки запускаются для установленного пакета.
Lockfile фиксирует разрешение Python-зависимостей, но не ОС, драйверы, оборудование,
модельные артефакты и mutable container tags.
