# ADR 0001 — Модульный монолит с явными границами

**Статус:** принято.

## Решение

Использовать один устанавливаемый пакет `agentic_rag` в `src/`; вводить модули только
когда появляется исполняемое поведение. Точки входа собирают зависимости, а доменная
логика не зависит от HTTP-фреймворка и конкретных SDK.

## Последствия

Сценарии можно тестировать без HTTP и заменять инфраструктуру на границах. Это не
гарантирует чистую архитектуру: направление импортов остаётся предметом ревью.
Микросервисы и крупный RAG-фреймворк отложены до измеримой необходимости.
