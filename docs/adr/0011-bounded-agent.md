# ADR 0011 — Явный ограниченный LangGraph-агент с read-only-инструментами

**Статус:** принято.

## Решение

Использовать один граф «модель → типизированный инструмент → модель/завершение» с
поиском, каталогом и калькулятором. Ограничить шаги, предложения инструментов,
историю, тайм-аут и бюджет; прямой ответ отмечать как не имеющий evidence инструмента.

## Последствия

Трассу исполнения и ошибочные аргументы можно проверить. Агент не получает прав на
запись; retrieved text рассматривается как данные. Лимиты останавливают петлю, но
не гарантируют своевременный полезный отказ.
