# ADR 0006 — Явные BM25 и reciprocal rank fusion

**Статус:** принято.

## Решение

Реализовать BM25 с прозрачной токенизацией и статистикой корпуса, затем объединять
его с dense-ранжированием через RRF. Порядок развития: отдельные baseline, fusion,
затем reranking.

## Последствия

Можно измерить вклад каждого сигнала и отладить разницу в результатах. RRF объединяет
ранги, не калиброванные scores; его константы и глубина кандидатов остаются частью
экспериментальной конфигурации.
