# ADR 0004 — Консервативная нормализация и сохранённые ревизии загрузки

**Статус:** принято.

## Решение

Хранить исходную идентичность, ревизию, нормализованный текст и координаты чанков в
одном определённом представлении текста. Очистка минимальна и детерминирована;
повторная загрузка не перезаписывает доказательства незаметно.

## Последствия

Ссылку можно проверить после смены текущей версии. Цена решения — хранение старых
ревизий и необходимость явно задавать политику их retention/удаления в будущем.
