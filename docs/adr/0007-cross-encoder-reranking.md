# ADR 0007 — Опциональный CPU cross-encoder для найденных кандидатов

**Статус:** принято.

## Решение

После hybrid-поиска по явному флагу оценивать ограниченный список пар
«запрос–пассаж» закреплённым cross-encoder и сортировать кандидаты по его logit.

## Последствия

Сохраняются исходные rank/score и измеряется candidate recall, поэтому улучшение
порядка не маскирует потерю на предыдущем этапе. Reranking увеличивает задержку и
не должен включаться без парного измерения на одинаковом пуле кандидатов.
