# ADR 0014 — Явные спаны, метрики процесса и опциональный экспорт Langfuse

**Статус:** принято.

## Решение

Создавать коррелированные JSON-логи и OpenTelemetry-спаны для запроса, поиска,
reranking, LLM и инструментов; собирать метрики с ограниченной кардинальностью.
Экспорт в Langfuse включается настройкой и не обязателен для запуска.

## Последствия

Локальная трасса работает без облака, а отсутствие секретов и полных промптов
уменьшает риск утечки. Наблюдаемость сама требует контроля стоимости и накладных
расходов; они не должны заявляться измеренными без отдельного бенчмарка.
