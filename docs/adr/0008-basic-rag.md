# ADR 0008 — Явный Basic RAG со сменяемой генерацией

**Статус:** принято.

## Решение

Отделить построение контекста, генерацию и проверку ссылок. Использовать
детерминированную подмену для тестов и OpenAI-совместимый HTTP-адаптер для внешней
модели; в контексте передавать идентификаторы чанков.

## Последствия

Неверные или отсутствующие ссылки отклоняются до выдачи ответа. Бюджет контекста и
выхода ограничен, но байтовый бюджет не равен токенам конкретной модели. Подмена
проверяет контракт, а не фактическую полезность текста.
